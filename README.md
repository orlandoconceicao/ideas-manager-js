# DevNotes

Aplicação web de estudo para criar e organizar anotações no navegador, com persistência local e exportação dos dados.

## Funcionalidades

- criação, edição, exclusão e duplicação de notas;
- fixação de notas importantes;
- pesquisa em tempo real;
- persistência com LocalStorage;
- exportação das notas em CSV.

## Tecnologias

HTML5, CSS3, JavaScript, DOM, LocalStorage e Bootstrap Icons.

## Execução

Abra o arquivo `index.html` no navegador. Os dados ficam armazenados no navegador utilizado.
